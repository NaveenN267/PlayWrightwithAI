## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/NaveenN267/PlayWrightwithAI.git
   cd PlayWrightwithAI
   ```

2. Install dependencies (if needed for Playwright-based exercises):
   ```bash
   npm install
   ```

3. Install Playwright browsers (if running browser automation examples):
   ```bash
   npx playwright install
   ```

## 📖 Learning Path

1. **Chapter 1: Basics** - JavaScript and Playwright fundamentals
2. **Chapter 2: JavaScript Concepts** - Core language concepts
3. **Chapter 3: Identifiers & Literals** - Naming rules and literals
4. **Chapter 4: Variables** - `var`, `let`, template literals, and practice
5. **Chapter 5: Operators** - Arithmetic, comparison, logical, and ternary operators
6. **Chapter 6: IF/Else** - Conditional logic
7. **Chapter 7: Switch** - Switch-case control flow

## 🛠️ Usage

Run any JavaScript example directly with Node.js:

```bash
node chapter_01_Basics/01_Basics.js
node chapter_04_Variables/20_Practice.js
node chapter_07_Switch/48_swithc.js
```

For Playwright tests:

```bash
npx playwright test
```
