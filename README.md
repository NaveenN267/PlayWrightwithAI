# PlayWright with AI

A comprehensive learning project for mastering Playwright automation testing with JavaScript fundamentals.

## 📚 Project Structure

```
PlayWrightwithAI/
├── chapter_01_Basics/              # Basic Playwright concepts
│   ├── 01_Basics.js               # Introduction to Playwright
│   └── 02_JS_Commands.js          # JavaScript commands in Playwright
├── chapter_02_Javascript_Concepts/ # JavaScript core concepts
│   └── 05_JS_Basics               # JavaScript basics
├── chapter_03_Identifier_Literals/ # Identifiers and literals
│   ├── 06_JS_Identifiers_Rules.js # Identifier rules and examples
│   └── 07_Keyborardshoutcuts_VSCode.md # VS Code shortcuts reference
└── README.md                      # This file
```

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/NaveenN267/PlayWrightwithAI.git
   cd PlayWrightwithAI
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Install Playwright browsers:
   ```bash
   npx playwright install
   ```

## 📖 Learning Path

1. **Chapter 1: Basics** - Introduction to Playwright and basic JavaScript commands
2. **Chapter 2: JavaScript Concepts** - Core JavaScript fundamentals
3. **Chapter 3: Identifiers & Literals** - Understanding JavaScript naming rules and literals

## 🛠️ Usage

Each chapter contains practical examples. Run individual files with:

```bash
node chapter_01_Basics/01_Basics.js
```

For Playwright tests:
```bash
npx playwright test
```

## 📋 Topics Covered

- Playwright automation basics
- JavaScript keywords and reserved words
- Identifier naming conventions (camelCase, snake_case)
- VS Code keyboard shortcuts for efficient development
- Best practices for test automation
