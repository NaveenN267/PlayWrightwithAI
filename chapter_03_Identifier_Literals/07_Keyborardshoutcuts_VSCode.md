# VS Code Keyboard Shortcuts for Windows

Here are common keyboard shortcuts organized by category. Use `Ctrl` instead of `Cmd` on Windows.

| Category | Shortcut | Description |
|----------|----------|-------------|
| **File Operations** | | |
| | `Ctrl + S` | Save file |
| | `Ctrl + Shift + S` | Save As |
| | `Ctrl + N` | New file |
| | `Ctrl + O` | Open file |
| | `Ctrl + Shift + N` | New window |
| | `Ctrl + W` | Close window |
| | `Ctrl + Shift + T` | Reopen closed tab |
| **Edit** | | |
| | `Ctrl + Z` | Undo |
| | `Ctrl + Y` | Redo |
| | `Ctrl + C` | Copy |
| | `Ctrl + V` | Paste |
| | `Ctrl + X` | Cut |
| | `Ctrl + A` | Select all |
| | `Ctrl + F` | Find |
| | `Ctrl + H` | Replace |
| | `Ctrl + Shift + F` | Find in files |
| | `Ctrl + /` | Toggle line comment |
| | `Ctrl + Shift + /` | Toggle block comment |
| | `Alt + Shift + F` | Format document |
| | `Alt + Shift + Up/Down` | duplicate line |
| **Navigation** | | |
| | `Ctrl + P` | Quick open (files) |
| | `Ctrl + Shift + P` | Command palette |
| | `Ctrl + Tab` | Switch between open files |
| | `Ctrl + Shift + Tab` | Switch backwards |
| | `Ctrl + G` | Go to line |
| | `Ctrl + Shift + O` | Go to symbol |
| **View** | | |
| | `Ctrl + B` | Toggle sidebar |
| | `Ctrl + Shift + E` | Show explorer |
| | `Ctrl + Shift + G` | Show source control |
| | `Ctrl + Shift + X` | Show extensions |
| | `Ctrl + Shift + D` | Show debug |
| | `Ctrl + Shift + Y` | Show debug console |
| | `Ctrl + `` | Toggle terminal |
| | `Ctrl + Shift + M` | Show problems |
| | `Ctrl + Shift + U` | Show output |
| **Debug** | | |
| | `F5` | Start debugging |
| | `F10` | Step over |
| | `F11` | Step into |
| | `Shift + F11` | Step out |
| | `Ctrl + Shift + F5` | Restart debugging |
| | `Shift + F5` | Stop debugging |
| **Other** | | |
| | `Ctrl + K Ctrl + S` | Keyboard shortcuts |
| | `Ctrl + K Ctrl + T` | Color theme |
| | `Ctrl + K Z` | Zen mode |
| | `Ctrl + Shift + P` | Show all commands |

**Tips:**
- Many shortcuts can be customized in VS Code settings.
- Use `Ctrl + K Ctrl + S` to view/edit all shortcuts.
- For macOS, replace `Ctrl` with `Cmd` and `Alt` with `Option`.
